# ระบบบันทึกการซ่อมบำรุงรถยนต์ราชการ
## โรงพยาบาลนิคมพัฒนา จังหวัดระยอง

ระบบออนไลน์สำหรับบันทึกและติดตามการซ่อมบำรุงรถยนต์ราชการ

### ฟีเจอร์หลัก
- บันทึกประวัติการซ่อมบำรุงรถยนต์ 11 คัน
- คาดการณ์ระยะซ่อมและแจ้งเตือนล่วงหน้า
- บันทึกเลขไมล์รายสัปดาห์
- ระบบ Login พร้อมจัดการสิทธิ์ผู้ใช้
- Sync เรียลไทม์กับ Google Sheets
- แจ้งเตือนผ่าน LINE Messaging API
- รองรับการใช้งานบนมือถือ (PWA)
- พิมพ์รายงานได้

### เทคโนโลยีที่ใช้
- Frontend: HTML5 + CSS3 + JavaScript (Vanilla)
- Database: Google Sheets
- Backend: Google Apps Script
- Notification: LINE Messaging API
- Hosting: GitHub Pages
